## Vision

### 10x Check
Tax-cellent becomes the first result when a new F-1 student Googles "how to file Form 8843
with no income." They answer 5 questions, click Generate, and download a print-ready,
legally correct Form 8843 in 10 seconds. No account required. No university access code.
No Sprintax fee. They bookmark it. Year 2, when they have income, they return for the
1040-NR — and Form 8843 is already pre-filled and auto-attached.

EUREKA: Sprintax is free via universities WITH an access code. Students in their first
days on campus, or at universities without Sprintax contracts, have NO access. Tax-cellent's
moat is zero-friction direct access — no code, no university partnership required.

### Platonic Ideal
A Chinese F-1 student arrives at MIT in September 2025. April comes. She types "form 8843
no income" into Google. Tax-cellent is the first result. She clicks "No income — just need
Form 8843." She answers 5 questions. Hits "Generate." Downloads a PDF that looks exactly
like an IRS form. Prints. Signs. Mails to the address on the cover sheet. Done in 3 minutes.
Next year, she gets an OPT job — Tax-cellent remembers her info and bundles the 8843 behind
her 1040-NR automatically.

### Backend — New Files
- `scripts/sync_constants.py` — reads `backend/app/constants/tax_constants.py`, auto-generates `frontend/app/lib/constants.ts` (just the `NRA_VISA_TYPES` export); run via `python scripts/sync_constants.py`; add to CI pre-commit hook and build script to eliminate Python/TypeScript drift
- `backend/app/services/form_generator.py` — PDF generation engine
  - `generate_8843(user_data: Form8843Data) -> bytes` — fills IRS form PDF template; primary strategy: pypdf AcroForm field fill by name; fallback: reportlab coordinate overlay using constants in `form_8843_fields.py`
  - `generate_cover_sheet(has_income: bool) -> bytes` — resolves mailing address and deadline from `has_income`; includes signing checklist (see Cover Sheet Logic)
  - `bundle_pdfs(pdfs_in_order: list[bytes | None]) -> bytes` — merges into single download; `None` entries are skipped; caller must pass PDFs in final document order: [cover_sheet, form_1040nr_or_none, form_8843]
- `backend/app/constants/form_8843_fields.py` — AcroForm field name → value map (primary); pixel coordinate fallback table for reportlab overlay if IRS PDF lacks named AcroForm fields
  - **SPIKE REQUIRED at implementation start**: open IRS Form 8843 PDF, check for named AcroForm fields (use `pypdf.PdfReader(f).get_fields()`). If fields exist → use pypdf. If XFA form or no fields → use reportlab coordinate table. Document the finding in a comment.
  - **EXPECTED_FIELDS validation**: `form_8843_fields.py` must also export `EXPECTED_FIELDS: set[str]` (the set of AcroForm field names the app writes to). `form_generator.py` validates on first use per tax year: if the loaded PDF is missing any field in `EXPECTED_FIELDS`, raise `ConfigurationError` with instructions to re-run `scripts/fetch_irs_forms.sh` and update `form_8843_fields.py`. This prevents silent blank-field PDFs when IRS updates the form mid-year. Cache the validated field dict in `_pdf_fields_cache: dict[int, dict]` to avoid re-reading on every request.
- `backend/app/schemas/form_8843.py` — `Form8843Data` Pydantic model
  - Part I fields (students): visa type, entry date, days in US, institution name/address, `exempt_prior_years: list[int]` (years already claimed), `catch_up_years: list[int]` (years being filed now as catch-up)
  - Part II fields (J-1/Q teachers/researchers):
    - Line 9: name of exchange visitor program
    - Line 10: name and address of sponsor organization
    - Line 11: number of years teacher/researcher has claimed exemption
    - Line 12: whether claimed exemption as teacher or researcher in prior 6 years (bool)
  - `role: Literal["student", "teacher_researcher"]` — determines Part I vs Part II routing; J-1 visa may be either; collected in ZeroIncomeStep (radio button shown only for J-1/Q visas; F-1/M-1 always "student")
  - `tin_status: Literal["ssn", "itin", "applied_for", "none"]` — drives Line 2 value:
    - `ssn` → print the SSN
    - `itin` → print the ITIN
    - `applied_for` → print "Applied for" (student awaiting ITIN)
    - `none` → print "N/A" (standalone 8843, zero-income, no TIN required)
  - `has_income: bool = False` — zero-income flag; drives standalone vs attached routing and cover sheet selection
  - `tax_year: int` — selects template from `backend/static/forms/f8843_{tax_year}.pdf`; defaults to current year; set to prior year for catch-up mode
  - `status_change_applied: bool = False` — Line 8 on IRS form; whether individual applied for nonimmigrant status change during tax year
  - `exempt_prior_years: list[int]` — years in which the individual previously claimed exempt status (drives Line 7 on IRS form; e.g. [2024, 2023, 2022])
  - `catch_up_years: list[int]` — years for which the user is now filing a catch-up 8843 return (drives template selection loop; e.g. [2024, 2023]); distinct from `exempt_prior_years`
  - Prior-year catch-up dropdown: populated from available templates in `backend/static/forms/`; if no prior-year templates exist, catch-up section is hidden in UI; current year always available
  - `NRA_VISA_TYPES` constant: defined in `backend/app/constants/tax_constants.py`; TypeScript copy auto-generated by `scripts/sync_constants.py` (new, runs at build time + in CI pre-commit); eliminates drift risk; CLAUDE.md sync note still applies as backup documentation

## Key Data: Form 8843 Fields

### Part I (Students — F, J, M, Q visa)
- Line 1: Name shown on tax return
- Line 2: Taxpayer identification number → driven by `tin_status` field:
  - `ssn` → print SSN | `itin` → print ITIN | `applied_for` → "Applied for" | `none` → "N/A"
- Line 3a: Days present in US during tax year
- Line 3b: Days excluded (medical, transit, etc.) — default 0
- Line 4: First date of current visit
- Line 5: Name and address of educational institution
- Line 6: Type of visa (F-1, J-1, M-1, etc.)
- Line 7: Number of calendar years individual has claimed exempt status under this visa
  - **Note**: IRS form has individual year checkboxes, not a count field. Map `prior_years_filed: list[int]` to the appropriate checkbox set. Verify actual field names at implementation via the AcroForm spike.
- Line 8: Did the individual apply for a change of nonimmigrant status during the tax year? (Y/N)
  - Mapped to `status_change_applied: bool`; default False

### Part II (J-1/Q Teachers/Researchers — `role == "teacher_researcher"`)
- Line 9: Name of exchange visitor program
- Line 10: Name and address of sponsor organization
- Line 11: Number of years teacher/researcher has claimed exemption under current visa
- Line 12: Has the individual ever claimed exempt status as a teacher/researcher in prior 6 years? (Y/N)

```python
def generate_cover_sheet(has_income: bool) -> bytes:
    if has_income:
        mailing_address = "Department of the Treasury\nInternal Revenue Service Center\nPhiladelphia, PA 19255-0215"
        deadline = "April 15"
        note = "Attach Form 8843 BEHIND Form 1040-NR when mailing"
    else:
        mailing_address = "Department of the Treasury\nInternal Revenue Service Center\nAustin, TX 73301-0215"
        deadline = "June 15"
        note = "File standalone — no tax return required with $0 income"

# Signing checklist items (printed on cover sheet):
# 1. Sign and date Form 8843 in ink on the signature line at the bottom of the form
# 2. Keep a copy for your records
# 3. Mail to the address above by the deadline
# 4. No payment required with standalone Form 8843
# 5. If filing for multiple years, send each year in a separate envelope
```
