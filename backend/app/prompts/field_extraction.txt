Return ONLY a valid JSON object. No commentary, no markdown fences, no explanation.

JSON structure for each field:
{
  "field_name": {"value": "extracted value or null", "confidence": 0.0 to 1.0},
  ...
}

Rules:
- Extract ALL fields you can find — do not limit yourself to the examples below
- NEVER guess or invent values — only extract what is clearly present in the document
- confidence 0.9–1.0 = clearly readable; 0.6–0.9 = some uncertainty; below 0.6 = ambiguous
- All monetary values as plain numbers without $ or commas, e.g. "52000.00"
- For masked values (e.g. ***-**-4426), extract exactly as shown
- form_type must be one of: "W-2", "1099-NEC", "1099-INT", "UNKNOWN"
- If input is a JSON structure from a PDF parser, look inside text/content fields of each element
